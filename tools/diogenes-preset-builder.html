Diogenes configuration & preset builder

Two things, on two tabs. Configuration is what is true of this machine — where Diogenes and your dictionaries are, which viewer opens a scan, which keys you want — and it writes the block for your init file. Presets is what varies with what you are doing: where the windows go, how much room each gets, how much of an entry to show. It writes a file you can load and change without touching your init file.

Dictionaries

A dictionary appears when its path is set and the file is there; an empty path means one fewer dictionary rather than a broken one. The key box shows the default — fill it only to change it, or type - to bind nothing.

Tick a dictionary to declare it (diogenes-declared-dictionaries): it is then offered on every entry of its language whatever its paths say, and pressing its key explains what to set. Worth ticking one you are about to install, or one whose files are somewhere this check cannot see. Leave it unticked and the paths decide, which is what most people want.

The key boxes here are the dictionary letters, and the same caution applies to them as to the keys further down: check each one in your own Emacs before settling on it. Open a Diogenes entry, press C-h k and the key, and Emacs names whatever holds it. What this tool knows is a curated list and cannot include your own packages or bindings.

Copy a file in your file manager and paste it into a box — the clipboard carries the whole path and the box takes it, on Windows, macOS and Linux alike. Typing works too. Dragging works in some browsers: most now withhold the path of a dropped file, the same rule that hides it in a file chooser, and the box says so when that happens. Nothing is uploaded anywhere.

On Windows, Copy as path in Explorer's right-click menu (hold Shift) gives what these boxes want. Backslashes are turned into forward slashes, which Emacs accepts and which keeps the generated configuration readable.

Keys

Blank keeps the default. - binds nothing, and the keyboard button records the keys you press.

Check every key in your own Emacs before you settle on it. What this tool knows is a curated list — Emacs itself, your distribution's usual bindings, evil, and the PDF viewer you chose — and it cannot know your packages, your modules, or anything you have bound yourself. Nothing here is a guarantee that a key is free.

The way to find out takes a moment. Open a Diogenes entry and press C-h k then the key: Emacs names whatever holds it, or says it is undefined. In a scanned dictionary do the same — the answer differs there. For a sequence under a leader, press the leader and let which-key list what is taken.

The C-c chords go between the windows and frames. They matter most with frames, where the kinds are in separate frames and C-x o cannot reach them — the key raises the frame and puts you in it. Within one frame they move between windows just as usefully. Press one twice where there are two of a kind, an OLD page and a TLL page say, and you go to the second.
